# hyperresearch (installed 2026-10-26, MIT, free; pipx at ~/.local/bin/hpr)
Deep-research harness for Claude Code / Codex; every source lands in a persistent markdown+SQLite vault reused next time.
Setup in a repo/folder: `hyperresearch install . ` (Claude Code) or `hyperresearch install . --target codex`
Then in Claude Code: `/hyperresearch <question>`; scholarly search: `hpr scholar search "<q>"`.
Team vault: run it in /workspace/team/research so all agents share one vault. Hosted version hyperresearch.ai is paid — don't sign up with a card.
