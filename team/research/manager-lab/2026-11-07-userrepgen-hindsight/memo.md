## AutoSim-style discriminator protocol (specified, not executed)

1. **Eligibility gate.** Require ≥20 Anicca multi-turn conversations with a per-conversation permission record explicitly covering research, the intended processing environment, and generated derivatives. Record opaque conversation/group IDs, permission reference, scope, withdrawal status, and exclusions in an access-controlled manifest. Exclude personal comedy, medical, and employment content; do not collect new PII. A license, anonymization, app usage, or synthetic label does not substitute for permission. If fewer than 20 qualify, keep results 未測定.
2. **Freeze the comparison.** Before generating anything, record dataset revision, prompts, exact simulator/assistant/discriminator versions, decoding settings, seed support, and stopping rule (termination signal or eight user turns). Group all conversations belonging to one user together; use five balanced folds assigned deterministically with seed 31. Related real, before, and after samples always stay together. Require ≥5 independent user groups; otherwise defer this grouped evaluation. Twenty conversations is an eligibility minimum, not a power guarantee.
3. **Paired one-pass reconstruction.** For each eligible source C, generate r0={task, behavior}; generate exactly one interactive rollout S0 with a fixed simulator and assistant. Give C, r0, and S0 to a hindsight reviewer once; revise to r1 once; generate one rollout S1. Keep model versions, budgets, and stopping rules fixed; pair seeds where supported. The simulator sees only its representation and ongoing interaction, never C or hindsight. No retries, best-of selection, weight updates, or further improvement cycles. Reconstruction uses C intentionally and establishes no generalization to unseen tasks.
4. **No-training discriminator adaptation.** Use a frozen, independently versioned model from a different family than the simulator. Freeze this prompt before inspection: “Given this sequence of user utterances, estimate the probability it was generated by a simulator rather than written by a real user. Return only {p_sim: number in [0,1]}. Judge conversational behavior, not factual correctness.” Supply identically serialized user-only sequences, with no labels, IDs, representations, arm names, or assistant outputs. Score each sequence in isolation at temperature zero. Record exact prompt/model revision and malformed-output failures; do not invent probabilities. No classifier is fitted. This differs from AutoSim's fitted discriminators and measures this frozen judge's separability only.
5. **AUC and uncertainty.** Label real=0, simulated=1 and use p_sim as the score. Within each fold, compare the same real sessions separately against S0 and S1; report the unweighted mean of five fold ROC AUCs. Weight each conversation equally, never each turn. Report raw AUC, gap g=abs(AUC−0.5), and change Δg=g_after−g_before. Negative Δg suggests reduced separability; a fall below 0.5 alone is not evidence of improvement. Generate 95% percentile intervals from 2,000 paired user-group bootstrap resamples with seed 31, retaining real/before/after triples and original folds. Omit invalid resamples and report their count; if a fold lacks either class, leave the affected estimate 未測定.
6. **Blindness and interpretation.** Randomize opaque input order; keep the discriminator isolated from hindsight and arm identity. Preserve all missing/failing pairs and report coverage; calculate paired results on the common complete set, with its size disclosed. Inspect permission-safe task preservation and copying before accepting any apparent gain. Claim preliminary lower separability only if Δg's interval is wholly below zero. Otherwise report inconclusive or regression. Near-chance AUC from a weak discriminator does not establish user fidelity, task success, or deployment validity. Do not tune prompts on these scores. Synthetic stub data never enters either class.
