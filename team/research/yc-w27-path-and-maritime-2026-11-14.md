### Maritime というプロダクト自体

Maritime（https://maritime.sh/、YC F26、サンフランシスコ、パートナー Pete Koomen）は、**AI エージェント向けのマネージドクラウド**である。船舶スタートアップのディレクトリではない。

公式の要約: 顧客ごとに隔離された永続 VM（Agent Box）を渡し、インフラ・スリープ／ウェイク・監視を任せる。Linux / Windows デスクトップ、Android 端末、評価・RL 用の Swarms もある。自前バックエンドのエージェントから MCP で Maritime のコンピュータを操作することもできる。料金の起点は公式 Launch 文で「エージェントあたり月 $1」から。CLI / REST / TypeScript / Python / MCP がある。

私たちの製品との対応: Life Manager Cloud は「顧客ごとに Maritime VM を1つ」という、公式が想定する使い方そのもの。公開ページ https://aniccaai.com/maritime（タイトル「Life Manager Cloud — hosted on Maritime」）。

### どれを Maritime に載せるか

選択肢は、成田さんの問いどおり次の4つ。

| D. アファメーションアプリ（Anicca iOS） | 無理に寄せれば Android Phone 上のモバイルエージェント、だが既存アプリは App Store のコンシューマーアプリであり、Maritime の「常時起動エージェント」ではない | 既存の有料は5本、直近7日の初回DLは数件。17日で1,000 人の **エージェント利用者** にするには、アプリをエージェントとして作り直す必要がある。Keiki / Maritime の利用として数えられる保証もない | アプリ自体は W27 に既に書いてある。Maritime 競技でこれを主戦場にしても、Maria の推薦理由（Life Manager Cloud）から外れる |

**推奨: A。提出済みの Life Manager Cloud を、リモートワークまたはクライアントワークの実作業が回るところまで改良し、外部の実ユーザーを取る。**

理由（証拠）:

1. **競技の勝ち方は「成長」であり「モデルの賢さ」ではない。** 公式文は “This competition is about growth: reach 1,000 users in six weeks.” 評価基盤やアファメーションアプリの再実装は、この指標を動かさない。
2. **すでに Maritime の正しい使い方で出している。** Typeform の草案も Maria のメールも、対象は Life Manager Cloud。途中で別物に切り替える理由がない。
3. **W27 の本道と一本化できる。** 応募文の次の一歩は「最初の外部フリーランサーが Manager に課金する」こと（`YC-APPLICATION.md`）。同じ証明が、更新と推薦と First 1,000 の三つに効く。アファメーションアプリの $20 MRR は既に書いてあり、ここを Maritime に載せても新しい信号は薄い。
4. **「改良した Life Manager が実際に仕事を自動化する」が、勝てるデモの中身になる。** 成田さんが挙げたリモートワーク／クライアントワークは、Capafy 一周や受託の自動実行という、社内ゴール（`MARITIME-GOAL.md`）と同じ線。サインインして終わるページではなく、同意のうえ実際に仕事が進むところまでが必要。
5. **ただし、1,000 人到達は現時点では見通せない。** 11/12 時点で fresh-tenant E2E 未完、Cloud MRR ¥0、外部有料ゼロ。隠さない。それでも、残日数で信号を動かすなら、提出済みの Life Manager に全振りするのが唯一の筋である。水増しは公式に失格対象。

今この競技でやること（優先順）:

1. 見知らぬ人が https://aniccaai.com/maritime からサインインし、自分の Manager が実際に1作業を完了する、という E2E を通す（これが無いと配布もユーザーカウントも始まらない）。
2. その作業を、リモートワークまたはクライアントワークの自動化（応募・返信・納品・報告のどれか1本）に固定する。
3. 実ユーザーを取り、Maritime / Keiki 上で検証可能な人数だけを数える。12/01 23:59 PT 時点の人数を、W27 の更新に正直に書く。
4. 1,000 人に届かなくても、検証済みの外部利用と「実作業が回った」記録は、推薦と W27 の更新に使う。
